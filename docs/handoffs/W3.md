card: W3 (sea colour round the Dovaran Crown)
status: DONE
date: 2026-11-23

**Cause:** the dark rectangle was the `HERO_Dovehall` box. Inside each hero box `M_Water` takes the sea-floor
elevation from the hero height texture (`hero_Dovehall_z.exr`, R = metres) instead of `T_TerrainData`. That
texture's sea pixels were ~10x too deep (median 4,627 m against the base terrain's 375 m, max 19,783 m), and the water
colour is a ramp on log depth with turquoise shallows below 160 m, so the box went dark and lost its islet halos.

**Landed** (fixed at the source, no shader change; `relief.gdshader` untouched)
- `tools/kw_edits/w3_sea.py`: every sea pixel (R < 0) of each hero texture gets the base terrain's elevation there
  (bilinear), kept at least 8 m deep so the hero's finer coastline stays water. Land pixels untouched.
  `T_Hero_GreatGate` has no sea pixels, so it isn't changed. Rebaked `atlas/assets/map/known_world/`.
- Backups: `KnownWorld.2026-11-23-pre_w3.bak.blend`, `textures/pre_w3/` (the script always starts from there,
  so re-running gives the same result).

**Check:** `docs/handoffs/W3_before_after.png` (baked albedo round Dovehall, before | after). `tools/run_tests.sh`
is green. `$GODOT --path atlas -- --map --map-mode=known_world --view=CAM_07_Veryan_to_Vaelwood`

**Notes**
- If W2 is ever re-run, run W3 after it: W2 rewrites `hero_Dovehall_z.exr` from `pre_w2`, which brings the deep
  sea back.
- The hero texture's land heights also look ~10x smaller than the base terrain's. That only drives the water's
  shore alpha (land is fully transparent either way), so it's left alone.
